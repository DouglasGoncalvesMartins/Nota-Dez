# NotaDez - Conectando Alunos, Transformando Notas

Site institucional do **NotaDez**, uma plataforma de apoio escolar peer-to-peer que conecta estudantes tutores do Ensino Médio a alunos do Ensino Fundamental que precisam de reforço nos estudos.

**[Acessar o site publicado](https://github.io)**

## Funcionalidades
- **Layout Responsivo:** adaptação automática para computadores, tablets e celulares, com menu retrátil em telas menores.
- **Seção "Como Funciona":** passo a passo visual explicando o fluxo entre cadastro, escolha da matéria e monitoria.
- **Filtro Interativo de Matérias:** visualização das disciplinas disponíveis por área (Exatas, Linguagens e Humanas) com botão direto para solicitar ajuda.
- **Depoimentos de Estudantes:** relatos reais de alunos e tutores sobre o impacto da plataforma.
- **Indicadores Animados:** contagem progressiva dinâmica na seção de resultados.
- **Modal de Inscrição Inteligente:** formulário interativo que já preenche automaticamente a matéria selecionada na página.

## Tecnologias Utilizadas
- **HTML5:** estruturação semântica da página.
- **CSS3:** estilização com Flexbox, CSS Grid e responsividade sem dependências externas para carregamento instantâneo.
- **JavaScript (Vanilla):** manipulação do DOM para filtro de matérias, controle do menu mobile, modal dinâmico, animação dos contadores e validação do formulário.
